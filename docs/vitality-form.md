The website submits directly to Jotform's normal form endpoint. Each submission is saved in Jotform and triggers the configured notification; replying to that notification addresses the person who signed up. Email is required; comments are optional and limited to 2,000 characters. No confirmation email is sent to the visitor.

The public page contains only the form ID, never an API key. Keep website field names (`q2_email`, `q3_comments`) synchronized if the Jotform fields change. API-created submissions do not trigger notification emails, so use the public form for end-to-end testing.

The interest list can be viewed and exported from Jotform Tables after signing into Nancy's account. Dates, location, and pricing remain undecided.
